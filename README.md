# 🎓 Student Career Hub

Student Career Hub is a web-based platform designed to help students explore and manage their career journey in one place.

## 🚀 Features

- 🗺️ Learning Roadmaps – Explore structured paths for different skills and career goals.
- 💼 Internships – Find and explore internship opportunities.
- 📜 Certificates – Showcase completed courses and certifications.
- 🚀 Projects – Display personal and academic projects.
- 👤 Student-Friendly Interface – Simple and organized navigation for students.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts
- Responsive Web Design

🎯 Purpose

The goal of Student Career Hub is to bring useful career resources into a single, organized platform so students can easily discover learning paths, internships, projects, and opportunities.
